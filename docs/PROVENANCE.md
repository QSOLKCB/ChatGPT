# Provenance and Clean-Room Record

## Origin

`QSOLKCB/ChatGPT` was created as an independent Linux-native agent-workstation project.

The project was motivated by general, publicly observable product concepts such as AI workspaces, terminal integration, command-line control, and computer-use agents. Its implementation is intentionally clean-room.

## Excluded implementation sources

No source code from `lencx/Noi`, `lencx/ChatGPT`, or other third-party desktop AI wrappers is to be copied, translated, mechanically reproduced, or incorporated into this repository without an explicit compatible license and a deliberate dependency decision.

## Allowed knowledge sources

Implementation may rely on:

- public operating-system API documentation;
- language and standard-library documentation;
- published standards;
- protocol documentation;
- properly licensed dependencies;
- independently designed architecture;
- black-box observation of publicly available software behaviour where lawful.

## Dependency record

Bootstrap authority core: Python standard library only.

Future dependencies should be recorded here or in a generated SBOM with name, version, license, purpose, and trust-boundary impact.
